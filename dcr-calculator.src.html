What the numbers mean

  • Max GFA — the total floor area the FAR permits on the plot.
  • Plot coverage — the GFA the code allows on the ground floor: plot size × max plot coverage.
  • GLA — leasable area, the share of GFA excluding cores, services and circulation.
  • Parking — ITC bays: employee/resident + visitor + truck/bus. Each activity contributes its exact figure; the total is rounded up once.
  • Activities — tenancies the GLA supports at the minimum unit size, rounded down.

Before you rely on it

  • The matrix holds — codes, each with a weekday and a weekend rate, from the ITC calculation sheet. Parking uses the week-weighted blend: 5 weekdays at 71.43%, 2 weekend days at 28.57%. Only 19 codes differ between the two tabs.
  • Rates are charged against different quantities per category — GFA, GLA, site area, or a count of seats, units, bedrooms, students, beds or doctors. The calculator binds the first three automatically and asks for the rest.
  • The sheet also carries trip generation rates (AM / Noon / PM / PHG) and the surveyed-site counts. They are stored in the database but unused by this calculator.
  • FAR and max plot coverage come from — designations in the Abu Dhabi Capital Development Code, picked in the Inputs panel. 15 publish no FAR — the Code governs those by note reference instead, so they cannot be calculated without an override.
  • The GLA 75% share is not a Code citation; set it per scheme.
